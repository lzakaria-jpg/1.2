# أدوات قيود — مدقق القيود + بناء شجرة الحسابات (PWA مستقل)

تطبيق ويب مستقل (خارج بيئة Claude بالكامل) فيه أداتين بتبويبين:
1. **استيراد القيود** — فحص وتجهيز ملفات القيود المحاسبية
2. **استيراد الشجرة** — قراءة شجرة حسابات العميل (أي صيغة) وبناء شجرة متوافقة مع قيود

## مهم جداً: تغيّرت طريقة النشر

النسختين تستخدمان الآن ميزة "المراجعة الذكية بالذكاء الاصطناعي"، وهذا يحتاج **دالة خادم صغيرة (Netlify Function)**
تحمل مفتاح Anthropic API بأمان. **طريقة "اسحب مجلد dist إلى Netlify Drop" القديمة لم تعد كافية** لأن Netlify Drop
لا يشغّل أي دوال خادم إطلاقاً — فقط ملفات ثابتة. الميزات الذكية (تشغيل المراجعة الذكية + تحليل شجرة العميل) لن
تعمل بهذه الطريقة.

### الطريقة الصحيحة الجديدة (لمرة واحدة فقط، ثم تلقائي بعدها)

1. **أنشئ حساب GitHub مجاني** (إذا ما عندك): https://github.com/signup
2. **أنشئ مستودع (Repository) جديد فاضي** من زر "New" الأخضر
3. من صفحة المستودع الفاضي، اضغط "uploading an existing file" وارفع **كل محتويات مجلد المشروع** (ملف `qoyod-pwa-source-كامل.zip` بعد فك الضغط) — لا حاجة لأي أوامر Git
4. اذهب لـ https://app.netlify.com → "Add new site" → "Import an existing project" → اختر GitHub → اختر المستودع يلي رفعته
5. Netlify رح يكتشف تلقائياً أنه مشروع Vite (بفضل ملف `netlify.toml` المرفق) — اضغط Deploy
6. **الخطوة الأهم:** من إعدادات الموقع بـ Netlify → Site configuration → Environment variables → أضف متغير جديد:
   - الاسم: `ANTHROPIC_API_KEY`
   - القيمة: مفتاح API من https://console.anthropic.com (تحتاج حساب Anthropic + إضافة رصيد)
7. من تبويب Deploys اضغط "Trigger deploy" → "Deploy site" عشان يقرأ المتغير الجديد
8. خلص! بعدها أي تعديل مستقبلي: عدّل الملفات بـ GitHub مباشرة أو ارفع نسخة جديدة، Netlify بينشر تلقائياً بكل مرة

### لو بس بدك الجزء الأساسي بدون الذكاء الاصطناعي (أسرع، بدون GitHub)

استخدم ملف `qoyod-pwa-dist-جاهز-للرفع.zip` واسحبه لـ https://app.netlify.com/drop زي المرة الماضية.
كل شي رح يشتغل **ما عدا** زري "تشغيل المراجعة الذكية" و"تحليل وبناء الشجرة" (رح يطلع خطأ اتصال عند الضغط عليهم).
الفحوصات الحاسمة (التوازن، الحساب الرئيسي، الرمز الموجود، صيغة التاريخ) تشتغل بالكامل بدون أي مشكلة بهذه الطريقة.

## التشغيل محلياً (للتجربة فقط، بدون AI)

```bash
npm install
npm run dev
```

## البناء اليدوي

```bash
npm install
npm run build
```

## تثبيت الأيقونة على الجوال

**أندرويد (كروم):** افتح الرابط ← القائمة (⋮) ← "إضافة إلى الشاشة الرئيسية"
**آيفون (سفاري):** افتح الرابط ← زر المشاركة (□↑) ← "إضافة إلى الشاشة الرئيسية"

## تحديث قالب قيود الرسمي مستقبلاً

استبدل `public/qoyod_template.xlsx` بالنسخة الجديدة، ثم ارفع التحديث لـ GitHub — Netlify بينشرها تلقائياً.
